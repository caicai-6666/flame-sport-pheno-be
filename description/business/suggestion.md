# 用户建议提交流程

## 业务目标

用户可在登录后提交产品建议或反馈，供后台后续查看和处理。当前阶段仅支持写入建议，不提供用户端查询、编辑或后台处理接口。

---

## 提交流程

接口：

```text
POST /flame/api/suggestion/remark
```

处理规则：

1. 从 `Authorization` 解析当前登录用户 ID。
2. 去除建议内容首尾空白；空内容直接拒绝。
3. 查询 `user` 表确认用户存在。
4. 在同一事务中向 `user_suggestion` 写入用户 ID 和建议内容。
5. 新记录默认 `status = 1`、`processing_stage = pending`，创建时间由服务端写入。

建议记录关联 `user.id`，不配置级联删除。用户停用或删除后的建议保留策略，待后台管理能力实现时再明确。

建议提交不受赛季开始配置保护期限制，保护期内仍可正常写入。
